# Solving for equal temperament voice leadings

## AI Use

I used Gemini Pro for generating much of the code given prompts such as "I would like to enforce traditional counterpoint rules to produce more interesting music. Can you suggest how to add them into the code below? <pasted main.py>". However, I wrote the comments myself (except for repetitive comments like labeling chord progressions), and I restructured the code several times to be somewhat more readable. My Gemini history is turned off, so I am unable to provide the exact prompts used. I also used Cursor for edits like properly formatting docstrings (while keeping my own written text, as I verified) due to the convenient diff displays.
